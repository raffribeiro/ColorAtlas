My palettes

Save a gradient you want to use again, then find it in My palettes. Give each snapshot a name and optional description. You can save the active ramp or both importance layers, and mark your own palettes as favorites.

My palettes opens by default whenever you start the app, including when it is empty. You can collapse it during the current visit; it opens again on the next launch.

Saving and loading

  1. Press the subtly outlined Save palette button beside the Gradient Map controls. Its softer text and border give Export PNG the stronger visual emphasis.
  2. Enter a name of 1–64 characters and an optional description of up to 240 characters.
  3. Press Save palette. Only the currently selected ramp is saved.
  4. Select a saved palette in My palettes to load it. Search matches its name and description.

Each save creates an independent snapshot. Duplicate names are allowed and create separate entries; saving does not overwrite an older palette. A snapshot keeps exact color-key HEX values and positions, alpha keys and positions, and each layer’s Smooth or Bands mode. Editing a loaded ramp does not modify its saved snapshot.

A single-layer snapshot replaces whichever layer is currently active. A two-layer snapshot restores Importance 01 and Importance 02 to their original roles, while keeping your active editing layer. Camera, preview filters, bloom, random mode, engine and source image are not part of the palette.

Favorites and deletion

The star adds or removes a palette from Favorites without loading it. User palettes also have an × button. It opens Delete palette? with the palette name; Cancel, Escape, the close button or backdrop dismisses the request. Delete palette removes the saved entry and its favorite reference. Built-in presets have no delete action. Deleting a saved entry preserves the colors currently in the editor and does not delete a PNG or external export.

Storage and limits

My palettes uses the same host state as the editor. The browser edition stores palettes in localStorage, under the current file path and query string. Reopen with the same browser profile and URL. This is a local library, without account sync.

Save and delete feedback stays in its dialog, without a message below Save palette, and waits for the host’s storage acknowledgement. If storage is unavailable, the change remains in the current session and an explicit message asks you to export key data before closing. A deletion that could not be persisted may return after reopening. Acknowledgement is not protection against browser data clearing or a moved file.

The saved-palette collection has an 8 KiB UTF-8 JSON budget within the host’s 16 KiB total state limit. Capacity depends on key counts, layers and metadata, rather than a fixed palette count. When full, a save is refused without adding or replacing a palette. Export important key data before deleting an unused entry. Restored entries are validated for supported layers, unique user IDs, bounded names/descriptions and 2–16 valid keys per channel.
