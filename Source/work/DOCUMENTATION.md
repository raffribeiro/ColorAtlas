## Verified technical distinctions

Copy HEX uses the clicked row’s uppercase six-digit HEX. The existing embedded app first attempts synchronous selection copying in an attached temporary textarea, outside hidden system panels, then tries the Clipboard API if needed. Success feedback includes the exact HEX and appears only on command/API acknowledgement. Unsupported or denied copying opens a native manual dialog with selected text; close and retry restore focus appropriately. Text is preserved for multiline export. The app does not read the OS clipboard back or widen iframe permissions; actual paste into another application remains a separate acceptance check. The compatibility command is deprecated and not a general recommendation for new integrations.

ColorPlay is an optional random mode inspired by Albers’s teaching exercises, preserving the Perceptual startup mode. It generates 16 candidate pairs, adapts hue-family boundaries to source-alpha-weighted coverage, and scores spatial neighbors and chroma area on a 32 × 32 source proxy against two neutral backgrounds. The shared preview mapper preserves active/combined/isolated-layer semantics and alpha. A bounded shortlist keeps diversity. Compare shows identical HEX patches on different surrounds and the current mapped proxy on dark/light grounds. Bloom, color-vision filtering and attention do not enter scoring or the study. The scoring constants are original app heuristics, not Albers formulas or a validated color-appearance model. Missing/fully transparent source data falls back to ramp-quality selection. Key counts, positions, alpha, active layer and preview mode are preserved.

The Color spaces and units chapter explains why OKLab is used and distinguishes the published conversion/Smooth interpolation from app-specific scaling, wheel presentation, gamut policy, relative-chroma controls and VFX workflow. The implementation is described as an OKLab-based gradient authoring tool, without a claim of a new scientific color model.

The authoring model and Smooth interpolation use OKLab, with L_UI=100L and a_UI=250a, b_UI=250b. The previous CIELCh labels were corrected to OKLCh. The Export PNG button opens the shared dialog, which offers PNG, Unity C# and Unreal JSON, active or both layers, transparency and Smooth interpolation. The standalone code-copy button and System/Engine selectors are hidden or removed; all format selection occurs inside export. This public workspace always renders VFX, preserving retained legacy-mode data. Perceptual (OKLab) defaults to the editor model; Linear RGB changes intermediate export colors without changing the editor. Unity perceptual code uses GradientMode.PerceptualBlend and ColorSpace.Linear with decoded linear-sRGB keys (Unity 6 documentation). Compatibility code uses Blend; Bands uses Fixed. Any selected layer beyond 8 color or alpha keys falls back to JSON preserving every key. Unreal OKLab metadata requires a custom evaluator or perceptually sampled PNG. Neither key rounding nor sampled 8-bit textures guarantee pixel-identical engine output.

Munsell data preparation adapts Illuminant C to D65 using Bradford and scales renotation luminance by 0.975. Saturation denotes relative chroma, and equal OKLab distances are not universal visibility guarantees. Harmony and attention are design heuristics. The original grayscale field uses encoded RGB bytes, while bloom, color-vision matrices, layer mixing and attention luminance operate in linear light. The effect preview is a 2D demonstration, not a simulation. Bloom, color-vision and attention do not enter gradient PNG export. Wheel picks always fit sRGB. The compact workspace hides the numeric alpha-value editor; alpha markers and alpha-key authoring are hidden. Empty ramp clicks and Position edit color keys only; retained opacity data still flows through saved snapshots, preview and export.

Standalone persistence attempts localStorage keyed by path and query string; if unavailable it falls back to session memory. Do not change the preview query string merely to refresh the page and assume saved state remains under the same key.

## Offline full-experience localization

`atlas-i18n.js/.css` adds the native header select. English remains the first-launch default. Editor, guide, interactive-example captions/readouts/canvas labels, tutorial, dialogs and contextual help use the selected language. `work/locales/*.json` owns short UI strings, `locales/full/*.json` owns source prose/dynamic templates, `locales/supplement/*.json` preserves text boundaries around inline code, and `locales/extra/*.json` covers runtime-derived controls and folder taxonomy. English authored source remains canonical. Keep key sets and numbered placeholders identical across languages; preserve mathematical notation, API identifiers, names and user-entered content.

Only leaf text and accessible attributes change. Original Text objects survive search highlighting, so switching locale restores the English source without replacing interactive elements or resetting controls. The guide rebuilds its localized section index while retaining chapter, query and reading position. Initialized examples repaint on locale change using their existing state. Canvas labels fit their allotted columns. Graph wrappers localize only the small text layer after drawing; English skips that work. No polling/render loop, network translation, or mutation of gradients/presets.

`atlas-i18n-host.js` validates iframe messages and stores a path/query-scoped preference independently of undo/library records. Runtime and all catalogs are embedded by `fit_local_page.py` outside the canonical size budget. The build requires all translated packs; missing/partial packs are a release failure. `extract_i18n.cjs` is a developer corpus helper using the installed Acorn parser; inspect new keys and inline-code boundaries before translating. It never runs in the shipped app.

Verify with `work/check_i18n.py`, `work/test_i18n_e2e.py`, `work/test_i18n_full_e2e.py`, the documentation/reset suite and onboarding suite. Use isolated browser profiles; tutorial restoration can reload its sandbox frame, so reacquire it after restoration. Tests distinguish UI source synchronization from actual localized browser acceptance.

The locale library wrapper accepts translated search labels without renaming presets or rewriting the query. Reverse aliases are indexed once and query expansions are bounded to64cached entries. Dynamic count patterns require numeric bindings, and hue templates accept three-letter labels such as hue. Accessible SVG/canvas attributes are translated separately from geometry/pixels. Focused regression: `work/test_i18n_dynamic_e2e.py`.
