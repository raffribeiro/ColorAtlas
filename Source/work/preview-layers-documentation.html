Image layers in Preview

Images have two Gradient Map ramps. Click edits; Shift-click selects more rows. Selection never changes dice. Chroma ON receives Random; OFF excludes. All OFF changes nothing. Outlined rows are active. Rename: 1–80 characters; Save applies, Cancel/Escape discards. Imports start OFF; legacy presets enable the active image.

Top rows are foremost; + imports, − removes, arrows reorder. Replace keeps maps. Checkboxes show images; Blend/Opacity edit the active row. Names truncate; empty stacks are transparent.

Up to eight PNG/JPEG/WebP images, 20 MB each, become grayscale 512 × 512 PNGs, centered with transparent padding and preserved alpha. Pixels use t = (0.2126 R + 0.7152 G + 0.0722 B) / 255 without stretching; Reference retains min/max normalization and a baked checkerboard.

Image compositing

Images blend back-to-front in linear sRGB with source-over alpha. Normal uses source color; Multiply uses b s; Screen b + s − b s; Overlay 2 b s below backdrop 0.5, otherwise 1 − 2(1 − b)(1 − s). Add uses min(1, b + s). This need not match Photoshop pixels.

a = aₛ + aᵦ(1 − aₛ)
C = [(1 − aₛ)aᵦCᵦ + aₛ((1 − aᵦ)Cₛ + aᵦBlend(Cᵦ,Cₛ))] / a

Alpha combines image alpha, ramp alpha and opacity. Bloom, vision and attention follow compositing. ColorPlay evaluates each Random target. Save palette/Export PNG use the active ramp; Export Preview flattens the scene.

IndexedDB stores images, names and maps separately from palette state, scoped to this path/query. Reload restores them. Session only means storage failed and edits remain in memory.

Preview presets

Presets store images, order, names, visibility, opacity, blend, active image, maps and dice (including all OFF). Maps retain colors, alpha, positions and Smooth/Bands. Loading applies Reset view: centered pan, height-fit zoom; stored zoom is ignored. Failed/superseded loads retain edits and view; select again to retry. Duplicate names create separate entries; Delete confirms and preserves Preview. IndexedDB: 16 MB plus browser quotas. Pan, bloom and vision are not saved.

Preview view controls

Preview fills its desktop slot; compact frames stay square. Images keep proportions on a borderless near-black blue background. Startup, Reset and successful preset changes center and fit height; manual zoom (1–400%) or pan overrides fitting. Middle drag has 15% edge room; left drag pans overflow. Comparison stays aligned.
