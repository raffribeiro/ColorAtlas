# Color Atlas v1.2.2 — release verification

Owner approved implementation and publication of security hardening and the GitHub presentation; subsequent steering requested 700% bloom and local uploaded-image persistence.

## Delivered behavior

Uploaded working images and layers now restore from browser IndexedDB on reopen, instead of being overwritten by Default. The Default scene remains the fallback for an absent or invalid saved scene. Normal startup never prompts to delete saved presets. A deliberate empty scene remains empty. Storage remains scoped to address and browser profile; no server uploads or cross-device sync were added.

Bloom supports 0–700%, retaining the authored 100% startup/reset and exact Undo/Redo rendering. Guide prose, interactive example and all nine catalogs match the new range and local scene behavior.

Host/frame CSP removes eval, remote executable assets and network connections while preserving the opaque sandbox. Inline scripts/styles remain required by the standalone architecture; this is hardening, not a claim that all injection risks are eliminated. Library imports validate schema/count/size before writes; chooser and drop inspect image metadata before decode. Correlated host replies check sender and boolean status.
